# Cloro: Tu Piscina Impecable

I want to create a website for an app that is simillar to this one: https://www.getskimmer.com/

I have a draft of the documentation of our MVP in the document attached, but keep in mind that we have these competitors too: 

Autocontrol Piscinas / Autocontrol Sistemas — directly solves the SILOÉ report problem
EviSane — generates the XML file ready to upload, plus Excel export per basin
EISI HOTEL — same XML generation but targeted at hotel pools (Tipo 2)

And that  in Spain, Whatsapp is used a lot, so include an agent that is connected to WhatsApp to assist the clients with a booking of the mentainance of the pool, so it needs to be connected to a calendar and have a brief for the client.

Don't build the app, but create the website mentioning all the features and capabilities, and client benefits, for the Spanish-speaking market.
